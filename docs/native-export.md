## 导出内容

导出当前已加载、显示姿态的静态网格，烘焙世界变换、蒙皮及形态。尺寸采用查看器当前识别的源单位：内部为毫米，glTF/GLB/VRM 转回米，PMX 转回厘米。单位下拉框只切换显示单位。

MAX/C4D/Blender 的原生修改器、程序化生成器及未保存的求值结果不会由导出器重新计算，导出的几何范围与当前查看器成功加载的范围相同。纯点云或曲线没有可导出的三角网格时会明确提示。

Markdown 文本不是三维模型，导出对象是当前说明卡平面；其中的文字不会自动变成三维文字。二进制 PMD/PMX 别名 `.md` 按实际 MMD 模型转换。

## 静态 VRM

- 文件是二进制 glTF 容器，含 VRM 1.0 的 `VRMC_vrm` 扩展和必需骨骼映射。
- 添加基础 T 姿态参考骨架，网格外形及尺寸保持不变。网格不自动绑定到参考骨骼，也不自动生成人体权重、动作、IK 或弹簧骨，因此不能作为已完成绑定的动态角色使用。
- 元数据中未提供的原作者标记为未填写，使用保守的 VRM 权限字段；源模型原有授权继续适用，转换不会额外授予使用或分发权限。
- 回归测试使用查看器重新载入，并独立使用官方 `@pixiv/three-vrm-core` 导入器构建 humanoid，检查骨骼映射、元数据、GLB 长度及未伪造蒙皮数据。
