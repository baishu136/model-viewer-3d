## 本次修正

### 0.5.1 Blender 场景修复

- Blender 写文件时可能在不同网格中复用临时 Attribute / AttributeArray 地址；改为按所属 ID 解析，避免读取其它网格的数据。优先读取 `position`、`.corner_vert` 和真实面偏移，不再依靠数据块大小判断属性用途。
- 新版不保存旧 `obmat`，因此从局部位置、旋转模式、缩放及增量变换重建层级；父级逆矩阵保留在独立节点，避免动画覆盖。对象名使用 UTF-8，轨道使用 UUID 绑定。
- Action 分层结构通过文件地址映射读取指针数组，按动作槽过滤；补全未动画化的属性分量，并按保存的贝塞尔手柄采样。多圈欧拉旋转先逐帧求值，再转换为四元数轨道。
- 基础修改器预览覆盖常量厚度 Wireframe（无顶点组、相对厚度或折痕）和至多三级 Catmull-Clark / Simple 细分（无折痕，限制输出规模）。这是几何预览，边界处理、细分极限曲面及厚度细节与 Blender 完整求值可能不同；Bevel、约束、蒙皮、几何节点等仍需烘焙，不能承诺与最终渲染完全一致。
- 真实场景对照原始顶点无误差，逐对象表面积最大相对差约 0.0146%（文字网格的三角剖分方式可不同）。第 1、90.75、180.5、360 帧各检查 328 个网格的世界矩阵：整数端点误差低于 `4e-7`，分数帧因逐帧采样插值，最大矩阵元素误差约 `0.0032`。
- Blender 仅用于测试时生成只读参考数据；查看器运行不调用或依赖 Blender。
- 本机部署的 0.5.1 实测打开原场景：328 个网格、70,866 个三角面、52,132 个预览顶点，时间轴拖动、动画播放及白模/布线切换通过，无渲染器或着色器错误；截图保存于 `screenshots/blend-scene-fixed-*.png`。

### 0.4.0 导入与导出适配

- 将 VRM 接入启动参数、拖放扩展名及 Windows 文件关联；0.x 与 1.0 的朝向修正在独立根节点上应用，避免动画覆盖。
- 压缩 VRM 共享顶点缓冲中的未使用顶点，同时保留所有蒙皮、归一化属性和形态目标，避免错误包围盒。
- 修正 PMX UTF-8 文本解析，并避免 PMX/PMD 重复读盘或依赖源贴图。
- 仅清除空形态数组，保留无动画模型的有效默认形态；空数组不再触发 MORPHTARGETS_COUNT 着色器错误。
- Maya ASCII 通过边表重建面，保留层级、旋转轴、轴心及 mm/cm/m 单位；Blender 和旧 FBX 使用凹多边形三角化。
- Cinema 4D 的坐标反射只应用一次，修复嵌套节点的 Z 位置；保留零缩放。
- GLB/glTF 导出从内部毫米转换为米，PMX 转换为厘米并写入有效根骨骼；修正 PLY 导出调用。7 种导出目标重新打开后均核对尺寸及面数。
- 空几何、非有限顶点/变换及越界面索引明确报错。

## 复现

```powershell
npm run typecheck
npm run build
npm test
npm run test:compatibility
npm run test:formats
npm run test:max
npm run test:blend
npm run test:blend:reference -- "场景.blend" --blender="C:\path\blender.exe"
npm run test:blend:viewer -- "场景.blend" --exe="C:\path\3D模型查看器.exe"
npm run test:formats:real -- "模型目录"
```

`test:formats:real` 按扩展名抽取不超过 64 MiB 的小、中、大样例，检查白模、布线、渲染器错误及源贴图请求，不修改原模型。最近运行结果保存在 `testdata/format-audit/real-models.json`，VRM 截图在 `screenshots/`。可附加已安装 EXE 路径验证部署程序。
