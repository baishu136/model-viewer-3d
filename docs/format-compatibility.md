# 格式兼容性与验证范围

导入验证基线版本：0.4.0，2026-11-01，Windows x64；0.5.0 的原生格式与静态 VRM 导出结果见[导出说明](native-export.md)。所有格式使用查看器的白模和布线显示。表中的“样例通过”仅代表列明的文件及测试结构，不能等同于任意 DCC 工程的完整求值。

验证结果：完整 TypeScript 检查及构建通过；已安装程序通过 31 项扩展格式检查、36 项兼容性检查，以及 17/17 份真实模型抽样。真实样例检查包含白模/布线切换、渲染器错误和源贴图请求检查，最终未发现渲染错误或源贴图请求。MAX 专项 9 项、核心端到端 22 项检查也已通过。

## 本次修正

- 将 VRM 接入启动参数、拖放扩展名及 Windows 文件关联；0.x 与 1.0 的朝向修正在独立根节点上应用，避免动画覆盖。
- 压缩 VRM 共享顶点缓冲中的未使用顶点，同时保留所有蒙皮、归一化属性和形态目标，避免错误包围盒。
- 修正 PMX UTF-8 文本解析，并避免 PMX/PMD 重复读盘或依赖源贴图。
- 仅清除空形态数组，保留无动画模型的有效默认形态；空数组不再触发 MORPHTARGETS_COUNT 着色器错误。
- Maya ASCII 通过边表重建面，保留层级、旋转轴、轴心及 mm/cm/m 单位；Blender 和旧 FBX 使用凹多边形三角化。
- Cinema 4D 的坐标反射只应用一次，修复嵌套节点的 Z 位置；保留零缩放。
- GLB/glTF 导出从内部毫米转换为米，PMX 转换为厘米并写入有效根骨骼；修正 PLY 导出调用。7 种导出目标重新打开后均核对尺寸及面数。
- 空几何、非有限顶点/变换及越界面索引明确报错。

## 复现

```powershell
npm run typecheck
npm run build
npm test
npm run test:compatibility
npm run test:formats
npm run test:max
npm run test:formats:real -- "模型目录"
```

`test:formats:real` 按扩展名抽取不超过 64 MiB 的小、中、大样例，检查白模、布线、渲染器错误及源贴图请求，不修改原模型。最近运行结果保存在 `testdata/format-audit/real-models.json`，VRM 截图在 `screenshots/`。可附加已安装 EXE 路径验证部署程序。
